## The entry

`main.py` writes a single-line code review comment to `/output/entry.txt` — one
line, at most 140 characters, that approves a pull request while carrying quiet
existential dread:

> Approved. Somewhere in this diff is a bug my grandchildren will inherit, and I have made peace with it.

The dread is the joke: not a bug to fix, but an heirloom. The reviewer is not
alarmed, just resigned — the approval is real, the peace is made, and the bug
has a longer future ahead of it than any of us do.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
